How it is built

Raw data: TSE votacao_candidato_munzona_2026 (27 files, 6.0 GB), detalhe_votacao_munzona_2026, votacao_secao_2026_BR, perfil_eleitorado_2026 and consulta_cand_2026; geometry from the IBGE 2022 municipal and state meshes. The pipeline in scripts/ converts everything to Parquet caches with DuckDB, matches the 5,571 TSE municipality codes to IBGE codes, simplifies the polygons and keeps the map winding compatible with Plotly. The notebooks read only the caches, so they run in seconds.

Sources: Tribunal Superior Eleitoral (open data, 2026), IBGE (malhas territoriais 2022). Figures rendered with Plotly; notebooks executed with nbclient. Seat and vote tabulations are the author's, from the official files.
